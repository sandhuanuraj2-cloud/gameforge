# GAMEFORGE

A Next.js starter for a cross-platform gaming strategy hub.

## What's included
- Responsive dark black, purple and electric-blue homepage
- PC, mobile and console positioning
- Eight game genres
- Search across the sample game library
- Category filters
- Featured game cards and strategy guide previews
- Community and moderation positioning

## Run locally
Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy
Import this project into a GitHub repository, then import that repository into Vercel. Add Supabase only when we build authentication and user-generated content.

## Important
This is a front-end starter. It does not yet include real authentication, database storage, user submissions, admin moderation, or live game data. Those will be added in later milestones.
